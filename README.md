## 🎯 How I Build AI

I follow a few simple rules when I build AI systems:

1. **Solve a real problem first.** I start with what the user needs, not with the latest model or trend.
2. **Make it reliable.** An AI that gives wrong answers is worse than no AI. I add checks for accuracy and hallucinations.
3. **Make it safe.** I build in protection such as PII redaction, jailbreak detection and output validation from the start.
4. **Keep it simple and scalable.** Clean, modular code is easier to test, improve and hand over to a team.
5. **Ship, learn, improve.** I build working versions early and improve them with feedback and data.
